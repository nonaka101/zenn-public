## 本書のスタンスと目的

本書は、私が情報システム部門での業務に就いた際、そこで作成した PowerShell の学習メモを基にしています。

当時は PowerShell に関する学習方法がわからず、また ActiveDirectory や Exchange Online に関する知識もなく、コツを掴むまで四苦八苦していました。

本書は そこでの経験から「同じような方に対し、**PowerShell を扱う取っ掛かりとなってくれれば**」と考え、作成したものです。

会社などに勤めている場合、そこではサーバを運用していることがほとんどだと思われます。そこで **Windows Server や Microsoft 365 系**などを扱っている場合、**PowerShell は非常に強力なツール**となり得ます。

本書は PowerShell の概要から始め、基本的な操作方法や構文について解説していきます。そして様々な場面で使えるユーティリティ関数を紹介し、最終的には ActiveDirectory などの操作を取り扱っていきます。

本書の目標は、PowerShell を使って組織内のシステムを管理する、その *第一歩を踏み出せるようにすること* としております。

:::message

よって本書は**入門用（初心者向け）という想定**で執筆しています。そのため *短縮表現は用いず できるだけ正式な書き方で表現する方針* といたします。

PowerShell にはエイリアスを使った短縮表現（例：`ogv`, `fl`, `ft`）が多く存在します。

しかし、例えば本書の中で `Format-List` と `fl` を混在して書いてしまうと、基礎ができていない初心者にとっては混乱する原因になりかねません。

そのため 本書ではそうした表現について、使用することも解説することもありません。PowerShell に十分に慣れてから、必要に応じて各自で調べてもらうようお願いいたします。

:::

## 想定読者

本書の読者としては、下記のような人物を想定しております。

- 企業の情報システム部門に勤めている方
- シェルスクリプト（例：`bash`）の基本的な部分は知っている方

### 企業の情報システム部門に勤めている方

「PowerShell で何ができるのか？」については次項にて説明していますが、基本的には **Windows で行うほぼ全ての操作ができる**というイメージで良いと思われます。

ただし、一般人が利用する範囲であれば PowerShell が必要になる機会というのは、ほぼ無いかと思われます。自動化が目的なら Power Automate などが選択肢になりますし、簡単なものなら コマンドプロンプトで十分だったりします。

**PowerShell が特に有用**なのは、Windows Server や Microsoft 365 などの **Microsoft 製品を運用している企業（組織）で、そのシステムを管理している情報システム系の仕事に携わっている方**だと思われます。本書はそれを想定して、情報システム系の方が扱うだろう各種サービス（ActiveDirectory, Exchange Online, Teams など）の操作について PowerShell を使った方法について最後の方で解説しています。

### シェルスクリプトの基本的な部分は知っている方

PowerShell を学習した際の私は、シングルボードコンピュータや Chromebook に搭載されている Linux 環境に触れ、そこで `bash` についての基礎を知っている状態でした。

PowerShell も `bash` などと同様にコマンドラインシェルとして利用できますが、全くの CLI 初心者がいきなり PowerShell を学ぶのは難易度が高いと考えています。

本書は「（学び始めた当時の）自身に教える」という想定で書いております。そのため読み始めるには、例えば下記のような *シェルスクリプトの基本的な部分* を知っていることが望ましいです。

- コマンドについての基本的な知識
  - コマンドとオプション（パラメータ）について
  - 入出力のリダイレクトについて（例：`>`）
- ディレクトリの構造についての基本的な知識
  - カレントディレクトリについて
  - ディレクトリ操作（例：`cd`）

:::message

こうした基礎知識は Web 上で探せば、動画やブログなどから多くの情報を見つけることができると思われます。いくつか読み漁って概要が掴めるだけでも十分です。

ちなみに もしコマンドラインでの操作に不慣れで、これまで GUI での操作が中心で CLI に触れたことがないような場合には、実際に**触りながら学習する**ことを強く推奨いたします。

例えば Raspberry Pi、Chromebook の Linux 環境、Windows の WSL（ *Windows Subsystem for Linux* ）、他にも 使っていない PC に Ubuntu を入れてみるなど、方法は様々あります。

:::

## 注意事項

ここからは、本書を読むにあたっての注意事項を説明します。

### 扱うコードには、危険なものが含まれています

PowerShell は、システム上の操作をシェルスクリプトで行うことができる強力なツールである一方で、**便利で強力であるが故に**、その扱いには細心の注意が必要となります。

そのため（**本書記載のコードを含め**）自身の環境上で実際に動かす際には、**自分がこれから行おうとしている行為が、どのような影響を与えるのか**を理解した上で行うようにしてください。

:::message alert

PowerShell は管理者権限を使って動かす場面が多いです。

管理者権限で実行する場合、下記のような**危険で取り返しのつかない操作**を（場合によっては警告なしで）行うことができてしまいます。

- ファイルの削除、コピー、改ざん
- インターネット経由でスクリプトを取得し、そのまま実行
- ユーザーアカウントに関する操作
  - アカウントの追加や削除
  - 様々な情報の取得（パスワードや資格情報 など）
  - 管理者権限の付与
- システムに関係する操作
  - ディスクやパーティションの初期化
  - システムフォルダへのアクセス
  - レジストリの書き換え
  - ネットワーク情報の取得
  - セキュリティ設定の変更

:::
