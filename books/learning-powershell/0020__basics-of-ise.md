## はじめに

ここでは、本書で主に扱っていく Windows PowerShell ISE（以降は PowerShell ISE と呼びます）について説明します。

「画面の見方」や「設定方法」など、本書を読み進めるために必要な情報に絞って話を進めるので、概要については下記の公式ページを参照してください。

https://learn.microsoft.com/ja-jp/powershell/scripting/windows-powershell/ise/introducing-the-windows-powershell-ise

:::message

本項以降は、ISE を使用して様々なコードを実行することを前提に説明します。

また場面によっては「管理者として実行」での ISE 起動が必要なケースがあります。初心者が常時 管理者権限で起動するのは危ないので、必要に応じて切り替えるようにしてください。

実行ポリシーを含め、自身の環境で行う処理や設定などは**ご自身の責任で行うもの**と認識していただき、コードの実行や設定変更を行う際は **ご自身で確認・判断を行う**ようお願いします。

:::

### 備考：スクリプトファイルの開き方と実行方法

PowerShellのスクリプトファイルには、拡張子 `.ps1` が使用されます。

ただしファイルの関連付けを変更していない限り、ファイルをダブルクリックしても PowerShell は実行されず、通常はテキストエディターで開かれます。

![PowerShell ファイルをダブルクリックしてテキストアプリが起動](/images/books/learning-powershell/ise-01.png)

スクリプトを PowerShell で実行する場合は、右クリックから「PowerShell で実行」を選択します。  
（※ この場合、PowerShell ISE でなく通常の PowerShell コンソールが開きます）

:::message

これも実行ポリシーや権限などの事情により、実行できない場合などがあります。

:::

![ファイルを右クリック](/images/books/learning-powershell/ise-02.png)

本書では PowerShell ISE を使った操作を行っていきますが、ファイルを右クリックした際の「編集（E）」を選択すると、PowerShell ISE を開けます。  
（起動するプログラムを指定し `.ps1` ファイルを PowerShell ISE で開けるようにしておく方法もあります）

### `x86` 版について

最もわかりやすい PowerShell の探し方は、スタートボタン（または Windowsキー）から検索窓を表示し、そこに `powershell` と打ち込むことです。

この際 検索結果としてアプリの一覧が表示されます。環境にもよりますが恐らく `PowerShell` を探す際、何も書かれていないバージョン（≒ 64 ビット版）と、`x86` と書かれたバージョン（≒ 32 ビット版）が見つかるはずです。

通常は、64ビット版の Windows PowerShell を使用し、`x86` 版は使うことはないと考えていいです。

:::message

`x86` 版は、システム上の 32ビット版のアプリケーションの操作や コンポーネントやモジュールとの互換性が必要な場合に使用します。

:::

##### 備考：インテリセンス機能について

PowerShell での基本的なコマンド（コマンドレット）は、`{動詞}-{名詞}` の形式となっています。インテリセンス機能を有効化すると `{動詞}-` 部を入力した段階で候補の一覧が表示されるようになったり、`Tab` キーでの入力補完が使えるようになります。

```ps1
Get-H  # <- ここで Tab キーを押すことで、候補を拾うことができる
<#
Get-Help
Get-History
Get-Host
Get-HotFix
（Tab キーで候補が先頭に戻り、再び Get-Help が表示される）
#>
```

また 変数名に続けて `.` を入力した段階で、メンバー候補の一覧を表示してくれたりもします。  
（候補を表示するには、事前に変数へ値を代入し、そのコードを実行しておく必要がある場合があります）

基本的には、インテリセンス機能は**有効にしておくことを推奨します**。

### コマンドアドオン

標準で利用できるコマンドや関数は数多くあり、モジュールを追加すると 利用できるコマンドはさらに増えます。

そして PowerShell 上でのコマンド名やパラメータ名は、比較的長くなる傾向があります。そのため、それらを 1 つ 1 つ覚えておくのは難しいでしょう。

都度 ヘルプを確認したり、インテリセンスで何ができるか調べるのも手だとは思います。ですがここでは、コマンドの確認や作成を支援するコマンドアドオンについて説明します。

![コマンドアドオン画面](/images/books/learning-powershell/ise-command-addon-01.png)

コマンドアドオンは PowerShell にインストールされているモジュール等から、実行可能なコマンドレットの一覧を持っています。

画面上部に「モジュール」と「名前」を指定する項目が用意されており、そこから調べたいコマンドレットを絞り込むことができます。ここでは `New-Item` というコマンドレットを調べ、選択しています。

するとフィルタリング項目の下に、コマンドレットに関係する項目が表示されます。基本的にはコマンドレットに紐づくパラメータの入力欄が表示されるはずです。

:::message

このパラメータ欄は、*入力欄にカーソルを当てることでツールチップ形式で簡易的に見る* こともできます。

![パラメータに関する簡易的な情報](/images/books/learning-powershell/ise-command-addon-03.png)

:::

パラメータを入力した上で 画面下部にあるボタンを押すと、下図のように 入力した内容がコマンドレット文として生成され、コンソール上で実行することができます。

![コマンドアドオンに入力して、それがコンソールに反映される](/images/books/learning-powershell/ise-command-addon-02.png)

:::message

各種パラメータの詳細については、ヘルプボタンから閲覧することができます。内容は、後の項でやる `Get-Help` コマンドレットとほぼ同じと考えて大丈夫です。

![ヘルプファイルを参照](/images/books/learning-powershell/ise-command-addon-04.png)

なお、**末尾の方に Microsoft Learn にあるオンラインヘルプの URL が書かれている**ので、そちらを参照すればより詳細な内容を知ることもできます。

:::

### スクリプトウィンドウ

その場でコマンドを入力して実行する場合、コンソールに直接書くことでも問題ありません。このスクリプトウィンドウでは、**記述したコードをスクリプトとしてファイル保存**ができるようになります。

また、ここでは下記のような機能を使うことができます。

#### 実行範囲の指定

スクリプトとして記述したものの一部を選択状態にして `F8` キーを押すと、**選択範囲内のコードのみ実行**することができます。

スクリプト全体を実行する場合は、メニューにある再生ボタン（`▶️`）から実行できます。また後述のデバッグ機能を使って、実行する処理を調整しつつ内容を追っていくことができます。

デバッグ機能は「作成したスクリプトを検証したい」といった時に、よく用いることになると思います。

#### ブレークポイント

スクリプトの途中で一旦処理を止めたい場合は、**ブレークポイント**が役立ちます。スクリプトウィンドウで止めたい箇所を右クリックすると ブレークポイントの挿入 といった項目があるので、それを選択するとブレークポイントを挿入できます。

ブレークポイントを挿入した状態でコードを実行すると、ブレークポイントの地点で一時停止状態にすることができます。

:::message

コンソール上でも、ブレークポイント等は設定可能ですが ここでは省略いたします。

:::
